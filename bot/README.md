# Аватар служебного бота «FBSM Уведомления»

`avatar-fbsm-uvedomleniya.png` — картинка 320×320 в гамме сертификатов обучения.
`narisovat-avatar.js` рисует её заново (node narisovat-avatar.js): если поменяется
оформление, правьте скрипт, а не подбирайте цвета руками.

## Как аватар ставится

Работает `user.update` — бот в портале всё-таки пользователь:

```
user.update { ID: 15495, PERSONAL_PHOTO: ["avatar.png", "<base64 картинки>"] }
```

Проверять результат надо `im.user.get` по тому же ID: поле `avatar` должно стать
ссылкой на cdn. Поставлено так 25 сентября 2026.

## Что НЕ работает — чтобы не пробовать снова

`imbot.update` фото не ставит ни из чужого вебхука, ни из того приложения,
которым бот зарегистрирован. `FIELDS.PROPERTIES.PERSONAL_PHOTO` строкой base64
или парой `["avatar.png", base64]` отвечает «ок», а `avatar` остаётся пустым;
варианты с `data:image/png;base64,…`, с полем в `FIELDS` напрямую и с
`{fileData: […]}` возвращают «Update fields can't be empty». При этом имя бота
и его код тем же вызовом меняются — поэтому ошибка и выглядит как проблема прав,
хотя дело в самом методе.
