# Для словаря программы kk.json — от обучения (19.10.2026)

Тренажёр переводит экраны словарём программы (kk.json). Надписей ниже в нём не было — в
тренажёре они переведены так. Если добавить их в kk.json этими словами, программа и тренажёр
совпадут.

| Русский | Казахский |
|---|---|
| ✓ Сдать отчёт | ✓ Есепті тапсыру |
| Сохранить изменения | Өзгерістерді сақтау |
| Отчёт за вчера не сдан | Кешегі есеп тапсырылмады |
| 🔒 Закрыть месяц | 🔒 Айды жабу |
| 🖌 Кисть | 🖌 Қылқалам |
| Поставить гостя | Қонақ қою |
| Подписать график за месяц | Айлық кестеге қол қою |
| Все точки | Барлық нүктелер |
| ✓ Всё по магазину сделано | ✓ Дүкен бойынша бәрі жасалды |
| Фактически в кассе | Кассада нақты |
| Режим просмотра | Көру режимі |
| Все даты | Барлық күндер |
| Пройденные ступени | Өтілген сатылар |
| Продавец месяца | Ай сатушысы |
| Магазин месяца | Ай дүкені |
| В штате | Штатта |
| Автоматически | Автоматты түрде |
| Нарушение прошлой смены | Өткен ауысымдағы бұзушылық |
| Мой план / Мои смены / Мои баллы | Менің жоспарым / Менің ауысымдарым / Менің ұпайларым |

Статуэтки: Десятка — Ондық, Слиток дня — Күн құймасы, Букварь — Әліппе, Сова — Үкі,
Кассовый аппарат — Кассалық аппарат, Караван — Керуен (Вега, Комета, Кактус — без изменений).
Антикубки: Дырявый зонт — Тесік қолшатыр, Громоотвод — Найзағайқағар, Сонная муха — Ұйқылы
шыбын, Разбитая копилка — Сынған жинақ қорапшасы, Кривое зеркало — Қисық айна, Грабли — Тырма,
Мистер Косяк — Мистер Қателік, Ржавая гиря — Тот басқан гір.

Расхождения внутри kk.json:
- «Вернуться к себе»: в plain «Өз аккаунтыма оралу», в записи «Что нового» — «Өзіме қайту».
- «Новые»: «Жаңа» против «Жаңалар».
- В записи про бота была опечатка «ұпайларыım» (латинская ı).
- «Примерочная» — три варианта (киім ауыстыратын / киіп көретін / киім өлшейтін бөлме); в курсе
  «Стандарт продаж» — «киім ауыстыратын бөлме», как в памятке фраз стандарта.

Полный список экранных строк тренажёра с переводом — kk/_trener_ekrany.json (plain + shablony).
